## Overview

A full-stack gamified learning platform inspired by the Japanese martial arts ranking system. Students progress through ranks — **Ronin → Kenshi → Samurai → Shogun** — by completing coding tasks, submitting GitHub repositories for review, and earning scores on a competitive leaderboard.

## Tech Stack & Architecture

- **Next.js 16 (App Router)**
- **React 19**
- **TypeScript**
- **Tailwind CSS 4**
- **PostgreSQL 16 & Drizzle ORM**
- **Redis 7 (ioredis)**

## Key Features & Highlights

- **Martial Arts Progression**: Rank progression system from Ronin to Shogun with XP tracking and streak counters.
- **Automated Judge Rubric**: Structured code review queue with multi-criteria scoring on architecture, test coverage, and performance.
- **Competitive Leaderboard**: Real-time rank leaderboard with streak multipliers and live updates.
- **Bento Grid Aesthetics**: Hyper-minimalist Japanese editorial design with sharp borders, ink wash elements, and smooth GSAP animations.
